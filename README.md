## Overview

EMH Model Finder offers a guided way to explore Canada's energy modelling landscape. Rather than requiring users to investigate individual tools one by one, it leads them through a decision tree designed to identify resources that fit their modelling needs.

The web interface is aimed at anyone researching energy modelling tools and related materials associated with the Energy Modelling Hub. It provides a focused, structured starting point for locating and comparing relevant Canadian options.
